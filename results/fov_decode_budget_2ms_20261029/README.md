# FOV timing：统一固定2ms解码预算

根据用户指定，所有档位按每帧一次 **2ms** 解码预算计算：`总时间 = 重建实测均值 + 2ms`。
2ms是统一预算假设，不是本次端到端实测，也不是RGB、depth、u、v各加2ms。多路联合解码及格式转换/互操作尚未联调。所有原始时间、质量数据与历史报告保留。
